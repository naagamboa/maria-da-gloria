# Site — Associação de Mulheres Maria da Glória

Prévia do site institucional da Associação de Mulheres Maria da Glória (AMMG), cozinha comunitária no Morro da Cruz, Porto Alegre/RS.

Site estático (HTML, CSS, JS, imagens e fontes), sem etapa de build. Basta publicar a pasta raiz.

## Publicação atual

GitHub Pages: https://naagamboa.github.io/maria-da-gloria/

## Como publicar no Vercel posteriormente

1. Importe este repositório no Vercel, ou rode `npx vercel` dentro desta pasta.
2. Não é necessário configurar framework, build command ou output directory: o site é estático e o `index.html` fica na raiz.
3. Depois, aponte o domínio definitivo da associação para o projeto na Vercel.

## Estrutura

- `index.html` — página única com todas as seções
- `assets/css/styles.css` — estilos
- `assets/js/config.js` — dados de contato e links
- `assets/js/data.js` — notícias e cardápio de exemplo
- `assets/js/main.js` — interações, acessibilidade e passeio guiado
- `assets/fonts/` — Fraunces e Atkinson Hyperlegible
- `assets/img/` — imagens e ícones

## Observação

O conteúdo está em validação com a associação. O próprio site exibe o aviso de que ainda não é o canal oficial.
